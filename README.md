# 配电箱智能识别报价系统

基于 Coze WebSDK 搭建的配电箱识别智能体网站。

## 功能特点

- ⚡ **AI智能识别**：上传配电箱系统图，AI自动识别元器件
- 📋 **秒级报价**：快速生成标准元器件报价表
- ✏️ **在线修正**：支持对识别结果进行人工修正
- 📱 **响应式设计**：支持PC和移动端访问

## 快速开始

### 方式一：直接在浏览器中打开

双击 `index.html` 文件，即可在浏览器中打开网站。

### 方式二：启动本地服务器

#### Windows 系统

双击运行 `start.bat` 文件，或在命令行中执行：

```bash
start.bat
```

#### macOS / Linux 系统

在终端中执行：

```bash
cd distribution-box-websdk
python -m http.server 8080
# 或
npx serve .
```

然后在浏览器中访问 `http://localhost:8080`

## 配置说明

### 1. 配置 Project ID

项目ID已预配置为 `7636692855800610831`，可在 `index.html` 中修改：

```javascript
cozeWebSDK.init({
    projectId: '你的项目ID',  // 替换为实际的项目ID
    // ...
});
```

### 2. 配置 Access Token

**重要**：WebSDK 需要认证才能使用。请按以下步骤获取并配置 Token：

1. 登录 [Coze 平台](https://www.coze.cn)
2. 进入 **个人设置** → **访问令牌**
3. 创建一个新的 **个人访问令牌 (PAT)**
4. 将 `index.html` 中的 Token 替换为你的实际 Token：

```javascript
refreshToken: () => {
    return '你的PAT_token_here';  // 替换为实际的Token
},
```

### 3. 发布智能体到 Web SDK 渠道

确保你的智能体已发布到 Web SDK 渠道：

1. 在 [Coze 编程平台](https://code.coze.cn) 打开项目
2. 点击 **发布** 按钮
3. 选择 **Web SDK** 渠道
4. 完成发布

## 常见问题

### Q: 网站打开后聊天窗口不显示？

A: 请检查：
1. 网络可以正常访问 Coze CDN
2. 已正确配置有效的 Token
3. 智能体已发布 WebSDK 渠道
4. 查看浏览器控制台是否有错误信息

### Q: Token 如何获取？

A: 
1. 登录 https://www.coze.cn
2. 点击右上角头像 → 个人设置
3. 选择左侧菜单 "访问令牌"
4. 创建新的个人访问令牌
5. 复制并替换到代码中

### Q: 支持哪些图片格式？

A: 支持 JPG、PNG、GIF、BMP 等常见图片格式，建议上传清晰的电气系统图或配电箱照片。

### Q: Token 安全吗？

A: ⚠️ **安全提示**：
- 本地测试时可使用 PAT Token
- 生产环境建议通过后端代理获取 Token
- 不要将 Token 提交到公开的代码仓库
